Media privacy & retention

No images, audio, or video are stored in the database

Uploads are converted and returned to the user. The database stores no media bytes, thumbnails, filesystem paths, object-storage keys, or media URLs.

What is retained

  • Website account email, password hash, credit balance, and payment identifiers.
  • Telegram ID, username, first name, language, Toman credit balance, first/last-seen timestamps, and Pro expiration.
  • Conversion metadata: channel, source and destination format, input and output byte counts, usage type, credit charged, and timestamp.

Operational note

Pending uploads remain only in process memory while the user selects a format. FFmpeg may use a private temporary input while processing seekable media; it is deleted immediately when processing finishes. This dashboard cannot view or recover uploaded media.
