Image privacy & retention

No images are stored in the database

Uploads are read into memory, converted, and returned to the user. The database stores no image bytes, thumbnails, filesystem paths, object-storage keys, or image URLs.

What is retained

  • Account email, password hash, credit balance, and payment identifiers.
  • Conversion metadata: source and destination format, input and output byte counts, allowance used, and timestamp.

Operational note

The Telegram bot keeps a pending upload only in process memory while the user selects a format, then discards it after conversion or expiry. This dashboard cannot view or recover an image.
